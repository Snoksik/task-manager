# Task Manager

Учебный HTTP API для задач на Go. Приложение использует слои handler → service → repository. Хранилище задач сейчас находится в памяти процесса; после перезапуска данные возвращаются к начальному набору. SQL-упражнения сохранены отдельно в `sql/` и пока не подключены к Go-приложению.

## Запуск

Требуется Go версии, указанной в `go.mod`.

```sh
go run ./cmd/app
```

Сервер слушает `localhost:8080`. Доступны:

- `GET /tasks`
- `GET /tasks/{id}`
- `POST /tasks`
- `PUT /tasks/{id}`
- `DELETE /tasks/{id}`

Пример:

```sh
curl -i -X POST http://localhost:8080/tasks \
  -H 'Content-Type: application/json' \
  -d '{"name":"Изучить PostgreSQL","user_id":1}'
curl -i http://localhost:8080/tasks
```

Поле `user_id` хранится в модели задачи, но существование пользователя в этой версии не проверяется. Валидация имени задачи находится в сервисном слое. Хендлер ограничивает размер JSON-тела и отклоняет неизвестные поля.

## Тесты

```sh
go test ./...
go test -race ./...
```

Тесты проверяют HTTP-хендлеры, сервис и локальный репозиторий. SQL-файлы — самостоятельная часть учебной работы; автоматические тесты Go их не запускают.
